
Grand Arena Setup Instructions:

1. Go to Supabase, create a new project.
2. Open SQL Editor and run 'supabase.sql' to create all tables.
3. Create a Storage bucket named 'results' for screenshots.
4. Host 'index.html' and 'app.js' on Netlify/Vercel or local server.
5. Update Supabase URL and ANON key in app.js if changed.
6. Open index.html in browser and test signup/login, wallet, tournaments, upload, admin actions.
